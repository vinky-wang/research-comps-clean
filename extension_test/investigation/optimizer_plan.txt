CONTROLLED OPTIMIZER INVESTIGATION

Original objects are retained and never replaced
No simulation data, priors, model formula or spatial projector is changed
All runs use INLA 23.04.24 and R 4.2 through the existing launcher

Six source fits: pilot and finer mesh versions of
  strength_case_0003_Melding
  clustering_case_0003_Melding (delta=2)
  strength_case_0003_PSmelding (gamma=1)

For each source, run three starts with tolerance=0.0001 (default=0.005):
  saved hyperparameter mode
  saved mode with areal variance initialized at 0.001
  saved mode with areal variance initialized at 0.1
Each uses the same saved latent mode x and restart=TRUE, fixed=FALSE
Changing initial values does not fix the variance at those values
The original finite-difference h=0.005, approximation, integration strategy and
variance correction are retained

Additionally, repeat the original pilot baseline Melding call twice and repeat
its tight saved-mode call once, giving 21 planned diagnostic fits in total
All calls use num.threads=1:1, the same saved R seed, and explicit one-thread
BLAS/OpenMP environment settings
The original fits already used 1:1 INLA threads
All attempts, warnings, complete fits and failures are recorded
No attempt is automatically retried; completed records are skipped on restart

Compare only within identical model/data/mesh when assessing log-posterior changes
Inspect modes, Hessian messages, posterior marginal shape, noise boundary
probabilities, predictions and transformed parameter summaries together
This is a bounded sensitivity investigation, not a guarantee of global optimization
Near-zero thresholds are diagnostic scales, not hard parameter boundaries
No prior sensitivity study or production changes are included

Documentation checked against installed defaults:
https://www.r-inla.org/learnmore/docs/reference/control.mode.html
https://www.r-inla.org/learnmore/docs/reference/control.inla.html
Installed defaults are saved in optimizer/runtime_controls.rds
