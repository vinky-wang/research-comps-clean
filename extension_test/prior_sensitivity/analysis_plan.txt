SMALL OBSERVATION-NOISE PRIOR SENSITIVITY
2026-10-22

Purpose
Assess whether the proposed observation-noise priors improve initialization
stability without materially changing latent-surface prediction in two saved
representative datasets. This is not a full simulation study or a test of
frequentist recovery. The original fitted objects and main scripts are preserved

Design
Datasets: baseline gamma=1 and independent clustering delta=2, both with
true point and areal variances 0.1. Both use I=100, J=25, N=2500, rho=.2,
sigma2=1, nu=1, and the same underlying latent response field
Fit both Melding and PSmelding on the existing finer mesh (2832 vertices)
Use the saved equal-vertex A_B and point-process quadrature unchanged

A: loggamma c(1,0.00005)
B: pc.prec c(0.316,0.5)
C: pc.prec c(0.5,0.5)
Apply each prior independently to BOTH Gaussian precisions
Point and areal likelihoods still have separate estimated variances
Leave the Poisson likelihood and all fixed/spatial/copy priors unchanged
This tests the combined observation-noise prior choice; it does not isolate
changing only the areal prior

Each prior/model/dataset has three initial areal variances: 0.001,0.1,0.4
Initial point variance is 0.1 in every run
Other hyperparameter starts and latent x are the same saved original starts
within each model/dataset. Re-optimize with restart=TRUE and fixed=FALSE
There are 36 planned fits, all retained; no selected result replaces an original
Tighter hyperparameter tolerance 1e-4, h=.005, inner latent tolerance and
posterior integration strategy unchanged. One INLA/BLAS/OpenMP thread
Identical fit seed within each model/dataset across priors and starts
This tests the areal initialization direction, not all possible initializations

Outputs
Save full fitted objects, warnings and logs, starting values and seeds,
posterior summaries, pointwise predictions, latent posterior draws and scores
Compute mean, median, SD and 95% credible interval for mu, both error variances,
gamma where applicable, rho, sigma2 and microergodic theta
Compute P(tau_B^2<.001), plus additional reference thresholds
MSE uses posterior mean predictions against the retained latent truth
CRPS uses 1000 joint latent-surface posterior draws, without new noisy responses
Keep Gaussian-approximation CRPS separately labelled
Use the same scoring seed across priors/starts within each model/dataset
This is not a guarantee of exact matched posterior draws

Report approximate CRPS Monte Carlo SE from 10 disjoint batches of 100 randomly
permuted draws. This is a diagnostic approximation to the full 1000-draw
U-statistic SE; cross-batch pairs are absent from individual block estimates
Matched-prior contrasts may also report paired block-difference MCSE

Prospective practical screens
Report all component results; these thresholds do not certify convergence
Within each prior/model/dataset across three starts:
  All fits/scoring successful and required summaries valid
  All mode_status=0, no negative Hessian eigenvalues
  No logged integration point more than .001 log units above reported mode
  Log-posterior-mode spread<=.01 (only compared within the same prior)
  Maximum pairwise mean/median/95% endpoint shift<=.1 pooled posterior SD
  Maximum pointwise posterior-mean RMS difference<=.01
  Range of P(tau_B^2<.001)<=.01
Also retain absolute parameter spreads; pooled-SD scaling can conceal broad tails

Predictive sensitivity
Use newly controlled A runs as reference, matching model, dataset and start
Report all contrasts and three-start ranges; never select the best CRPS result
Flag absolute relative changes>5% in MSE or joint CRPS as potentially material
Also report absolute CRPS differences and the 0.01 absolute threshold used in
the earlier pilot. Keep Monte Carlo uncertainty visible for small differences
A large change can be an improvement or deterioration, not automatically a failure
Do not treat the three starts as independent simulation replicates
Do not rank priors by raw log-posterior-mode values across different priors
If A is initialization-sensitive, its predictive comparison is ambiguous;
show that dependence rather than hiding it in an average

Documentation
INLA pc.prec uses P(sigma>u)=alpha, sigma=1/sqrt(q)
B therefore has median variance 0.316^2=.099856, C has median variance .25
https://inla.r-inla-download.org/r-inla.org/doc/prior/pc.prec.pdf
